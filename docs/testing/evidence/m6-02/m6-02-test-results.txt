DEFECT FOUND AND CORRECTED

A complete cached product was previously returned before connectivity affected the
source state. A recent saved result could therefore appear fresh while the device
was offline. Connectivity is now part of the cache decision, so every offline saved
result is clearly labeled as an offline copy with unconfirmed freshness.
