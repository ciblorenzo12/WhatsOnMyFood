# What's On My Food 2.0.0-beta

Signed Android beta, version code 21. Unlimited AI testing remains enabled.

## Changes

- Normalizes local source-quality estimates to a 0–100 scale using the 92-point raw maximum, with quality bands applied after normalization.
- Converts server scores marked `source_quality_v1` using their 99-point raw maximum. Scores marked `source_quality_v2`, or with missing or unknown method identifiers, retain their supplied scale.
- The backend source supports `source_quality_v2` and returns normalized scores with `raw_score` and `raw_max`. Activation on the hosted service requires a separate backend deployment; this APK also handles existing v1 responses.
- Retains the previous candidate's allergen highlighting, named certification labels, and organic wheat sourcing fixes.
- Updates the release identity test to enforce `2.0.0-beta` / `21`.

Source-quality scores remain heuristic estimates, rather than probabilities of claim accuracy. The scoring details are in [Scientific source quality verification](../testing/source-quality-verification.md).
