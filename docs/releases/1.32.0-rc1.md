# What's On My Food 1.32.0-rc1

Local release candidate prepared October 3, 2026. Android version code is 19. Signed APK and AAB were built; this preparation did not install, upload, or publish them. Unlimited AI testing access remains enabled.

## Changes

- Organic product labels now prevent a contradictory non-organic wheat warning when an ingredient is listed simply as whole grain wheat. Organic wording is checked consistently, negated claims are rejected, and buckwheat no longer matches wheat. Includes regression tests (commit `4296956`).
- Includes the recall screen information improvements from `9f9859b`, with clearer recall details and actions.
- Updates the version identity and its regression test. The build retains the existing local Android Gradle plugin update to 9.3.3.
